# 🎮 XO Nova — Tic-Tac-Toe

A modern, responsive Tic-Tac-Toe game featuring a neon-inspired design, interactive gameplay, score tracking, and offline support.

🔗 **Live Demo:** [Play XO Nova](https://ayesha-nisar-1011.github.io/xo-nova/)

## ✨ Features

- 🎨 Modern dark neon UI with cyan, pink, and purple accents
- 📱 Responsive design for desktop and mobile devices
- 🎮 Interactive Tic-Tac-Toe gameplay
- 🤖 Play against the computer or challenge a friend
- 🏆 Score tracking for X, O, and draws
- 🔄 Start a new round or reset the scores
- 📲 Progressive Web App (PWA) support
- 📡 Offline gameplay using a service worker

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling, responsive layout, and animations
- **JavaScript** — Game logic and interactivity
- **Web App Manifest** — PWA configuration
- **Service Worker** — Offline caching
- **Git & GitHub** — Version control and hosting
- **GitHub Pages** — Deployment

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ayesha-nisar-1011/xo-nova.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser, or use a local development server for testing PWA features.
